# OfferAnchor: Work-Package Handoff

Use this template for a consumable artifact, review request or blocker. The [work-package map](publication-scope.md#excluded-material) supplies ownership and permitted paths; the [manifest](project-manifest.json) supplies versions and profession-based member identifiers. A producer's self-check is not consuming-owner acceptance.

Copy one record into the agreed shared issue/PR. A new repository handoff path requires explicit ownership and task-path assignment first; no `docs/handoffs/` writer is currently assigned. Keep participant identities, contact details, selected real evidence, credentials and private raw records outside Git. Public links must be accessible to the intended reviewer; a private local path is not shared evidence.

## What acknowledgement means

CS importing the analysis module and exercising its current fixtures is acknowledgement; receiving a screenshot or a completion message is not. AI loading the approved content version and rejecting unknown/draft live IDs is acknowledgement. Design inspecting real UI states/strings is acknowledgement. DASE running the same frozen module or checking annotation rows/whole-case results is acknowledgement. Communication checking actual aggregates/source approvals before a slide consumes them is acknowledgement.

Profession labels can identify reviewers/consumers without personal names. Do not prefill approval dates or results; a role label alone is not a real human review. The producer may record an actual message/issue reference once received; missing acknowledgement stays pending. Completion follows observed self-check, different principal reviewer, consuming-owner acknowledgement, integration and explicit human/user acceptance. Local AgentBoard `done` still requires the user's actual acceptance.

## Quick examples of adequate evidence

- `Authored fixture, simulation mode; schema/quote check observed; no live-model conclusion.`
- `Current build rejected old request/revision after an edit; synthetic case and actual UI result attached.`
- `Source/card reviewed by the named teammate on the recorded date; service scope retained; no partnership claim.`
- `4 consenting students actually completed the primary comparison; planned target was 6-8; allocations, six rubric items and limitations included.`

These are wording examples, not results that occurred. Never copy them into the result ledger as observations.
