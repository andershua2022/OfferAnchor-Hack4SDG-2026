## Released scope

The public product is https://offeranchor-hk.vercel.app. The formal source is OfferAnchor and its verified team GitHub branch. It supports selected recruitment/onboarding text, context and later replies; financial/account interpretation with original passages; bounded correction/clarification; protected editable briefs; file/image intake; Learn, knowledge Q&A and optional public search. It does not certify a job/employer, perform a financial operation, contact third parties or assess all employment rights/privacy.

The initial study and main competition story remain students/early-career applicants encountering requests involving their money or account control. Broader Hong Kong jobseeker eligibility is not evidence of effectiveness for every worker. This is a restricted free trial, with unresolved quality/device/effectiveness limits.

## Input, knowledge and data

TXT/Markdown/DOCX and text-PDF convert locally into inspectable text. Images/scanned-page reading require separate consent and a configured server image route; the configured vision model is separate from core analysis. Original image bytes sent for that feature leave the device. AnalyzeRequest itself remains text-only. Intake is not document-authenticity verification.

The knowledge source set has seven approved cards across four routes, with separately labelled published cases. Q&A retrieves from that source set. Optional Firecrawl search starts only on deliberate user action and can be skipped or fail; it is not a mandatory step of every analysis and does not automatically visit suspicious submitted links. Source retrieval is not employer verification.

Accounts and temporary auth/quota coordination are stored by their configured cloud services. **Cloud query history and cross-device evidence synchronization are not implemented.** Working material stays in the page unless deliberately sent for a selected provider feature or exported. Optional browser history is simulation-only. A readable ZIP contains report.html, record.json and README.txt. Strict reimport restores input for editing/new analysis, not a trusted old result; it makes no automatic model call. A subsequent live analysis uses the normal allowance.
