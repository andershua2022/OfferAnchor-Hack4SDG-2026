# Public functional scope — 21 October 2026

This kit separates reviewable implementation from the production visual design.
The full website is still available at https://offeranchor-hk.vercel.app. The
source selection itself does not deploy, alter services, or change ordinary
accounts' five lifetime action attempts. This kit is based on the published
19 October source, not the pending local finals-code candidate.

## Included

Core extraction/audit/validation, hard safety policies, optional local-source Q&A
and Firecrawl adapters, API security and quota controls, source provenance,
functional browser state/file/account/export adapters, public schemas, synthetic
cases, frozen nonvisual evaluation inputs and reproducible tests are retained.
The plain reference client is a separate presentation shell using the same core.
It intentionally supports fewer convenience interactions than the complete product.

## Excluded material

Production landing/workspace/login markup, all original production CSS, logo
vectors, custom font resources, motion assets, screenshots, design-frame graphs,
visual mockups and internal collaboration instructions are not included. The
complete private working source is retained. Visual/design-only test suites are
excluded along with their inputs, rather than replaced with false pass claims.
File-reader vendor code remains because it implements local document conversion.
The portable report's simple readability/print CSS is functional export code,
not the product page design.

Older dated technical records may refer to the full private product or its former
file inventory. They are historical evidence, not a promise that withheld visual
or internal-team documents ship in this kit. The publication manifest owns this
snapshot's file boundary; README owns its current runnable commands.

## Evidence and rights

Source readability improves auditability; the competition rules do not establish
an automatic open-source score bonus. A live demo and the problem/GenAI/impact/
ethics evidence remain the main submission materials. Historical results remain
dated observations, not held-out accuracy. No trial user records are released.

The repository has no blanket team-code open-source license; this change does not
silently grant one. Original rights and applicable third-party terms remain.
If history is replaced with owner authorization, that changes current branch
reachability, not copies already downloaded, existing forks or host caches. No
claim of complete historical erasure is made. Private source and complete local
history are preserved before any remote operation.
