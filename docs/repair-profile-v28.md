# Local source-role and same-payment repair profile

This profile is an isolated, reviewable backend candidate. Its source is in the separate laboratory worktree. It has not changed the canonical app or hosted deployment. Public contract 2.0.0, the financial/account scope, account trial limits and frontend flow remain unchanged.

## Runtime

`lib/analysis/index.ts` selects `extract-v2.28`. `createSourceBoundProvider` routes it to the existing two-request context pipeline with `context-audit-1.7.0`. Both phases share the original 50-second provider budget; the outer analyze limit stays 53 seconds. Each attempted model request counts. No retry, automatic repair or extra model is added.

1. Catalogue original source slices and keep their literal citation identity.
2. Compile recipient capabilities from the same original-source marker function used by generation-schema and cited-unit validation. Explicit company HR departments are supported; generic HR, us, job purpose, printer and task-platform affiliation stay uncertain. Metadata availability is never actual receiver binding or verified sender authority.
3. Compile up to four finite same-payment reference hints only for one unambiguous HKD amount/earlier payment with later explicit identity wording. Decline hints for known original funding, distinct events, negative identity/currency corrections or malformed amounts. Metadata contains controlled unit IDs/enums/normalized amounts, not arbitrary source prose.
4. Supply identical capabilities/hints to generation and audit as bounded system metadata. Original evidence remains separate user data, and canonical citations resolve against original unannotated input.
5. Generate one financial/context wire. Keep compatible initially unspecified funding and later same-payment funding as one action citing both sources plus a targeted funding claim. Preserve distinct payments, original personal demands and contradictions.
6. Keep all existing schema, recipient, repayment and canonical checks. Reject a leftover unknown/company duplicate or a stale unknown tuple when the model itself targets compatible company funding. No row is rewritten, dropped, merged or silently upgraded.
7. Run the independent source audit. Findings remain fatal and retain paid usage. Cancellation and unknown phase usage retain their existing behavior.

## Boundaries

Same-payment hints use finite English/Hant/Cantonese wording and explicit HKD references. Absence of a hint never proves two events are distinct; presence is not proof of funds or safety. Ambiguous multi-event/other-currency originals can fall back to no hint and ordinary source analysis. Unsupported semantics still cause an incomplete answer, rather than a financial instruction or invented certainty.

The local gateway runner reads only the existing authorized test configuration at runtime, outside the worktree. Production should keep the team-provided Alibaba model configuration, with keys on the server; users do not enter their own key. The gateway test runner and its config paths are experimental tools, not production dependencies.
