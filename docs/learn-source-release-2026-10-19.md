# Learn public-source expansion — 19 October 2026

This release expands public-source records from six to 24 while retaining the seven separately approved core guides. It fixes exact source identity matching, adds bilingual keyword metadata and clarifies the existing optional public-search controls. The tested candidate is published; the same staged deployment was promoted after the checks below. Core extract-v2.29 / context-audit-1.8.0, contract2.0.0, page layout/CSS, team Alibaba configuration and five lifetime AI action attempts per account remain unchanged. Semantic search is not implemented.

## Content and boundaries

The 24 records comprise eight reported cases, twelve official guidance summaries and four company practices, covering payments, personal borrowing, account control, data collection, ordinary company/agency arrangements and next steps. There are 22 unique source URLs. These are editorial paraphrases with source, date, jurisdiction and limitations; they are not 24 victim transcripts, approved gold tests, verified employers or 24 new automated analysis capabilities. Public summaries remain human-review-pending. Existing seven-guide human approval is not extended to the new records.

Official guidance is labelled separately from reported cases. Hong Kong agency commission is a normal comparison with stated conditions, not an instruction to pay. US FDIC and FBI examples are explicitly international comparisons. Two unavailable FTC links were replaced by the original FDIC archive and FBI alert, with summaries adjusted to those exact sources. Raw victim messages and competitor text are not reproduced.

## Retrieval and public search

Source IDs now match the entire recorded URL, with a record's own ID when no exact registered source matches. Unrelated trailing-slash pages cannot share an identity. Live knowledge answers exclude draft passages before ranking and continue to use reviewed core wording. Learn and related Check material use the same corpus. Card search is local keyword matching with curated English/Traditional/Simplified Chinese terms, not vector semantic search.

Firecrawl needs no keyword in the user's prompt. In the existing Sources & questions panel choose Public sources, review a general query, then Find sources. Knowledge questions still disclose transmission to the project AI; public search explains that only its reviewed query is sent and personal data should be omitted. Search is optional, failure may be skipped, and results neither verify an employer nor overwrite a reading. Paid searches/knowledge answers retain the existing shared five-action account policy; local card filtering makes no API call.
